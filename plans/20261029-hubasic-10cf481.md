# X1Pen: HuBASIC bundle from SLANG-compiler 10cf481 (CONSOLE, CHR$(14)/CHR$(15), PRINT , wrap) and the reference review

## Purpose

SLANG-compiler PR #247 is merged at `10cf481e99161fcf1a9b4a2d2b33db327878b47c`. X1Pen bundles hubasic2sl and the x1native runtime from `55e7271336d4e92206b718edce6bad37a5b4c7f8` (PR #144). This PR does three things:
- replaces the bundle with 10cf481;
- reviews the x1pen-mcp HuBASIC reference (`mcp/reference/hubasic.json`) against 10cf481. The stamp test from PR #142 fails until that is done;
- checks in X1Pen that the CONSOLE window behaves as slang's docs describe.

The reference must:
- add a `CONSOLE` entry. It must say plainly that `LOCATE`, `TAB`, the `PRINT ,` stops, `CHARACTER$` and `SCRN$` use absolute screen coordinates, not window-relative ones, and that `LOCATE` outside the window is error 5. ひろしさん expects AI to trip on exactly this;
- say that `CHR$(14)` and `CHR$(15)` now work, with or without a window;
- describe the new `PRINT ,` wrap at the right edge;
- add the new known differences from `docs/HUBASIC.md`.

Rights rule (ひろしさん's): write the reference only from SLANG-compiler sources and `docs/HUBASIC.md` at 10cf481 (MIT, ひろしさん's repository) and X1Pen's own code. Never read, copy or paraphrase the HuBASIC manual.

- Runtime (`libx1_basic.asm`):
  - New work area `BAS_WIN:4`: left, top, right, bottom, inclusive. The full screen is 0, 0, width-1, 24.
  - `BAS_CONSOLE`: sets the window to rows ys..ys+yl-1 and columns xs..xs+xl-1 and moves the cursor to its top-left. The ranges are ys 0-24, yl 1-(25-ys), xs 0-(width-1) and xl 1-(width-xs); anything else is error 5 ("HuBASIC の実測").
  - `BAS_CONSOLEY`: the same, with all columns.
  - `BAS_CONSOLE0`: restores the full screen without clearing or moving the cursor.
  - `BAS_WINRST` is called from the shared INIT state (start-up and the `INIT` statement; the cursor does not move) and from `WIDTH`.
  - `BAS_LOCATE`: "画面の絶対の座標。テキストの窓 … の外はエラー 5".
  - `BAS_CLSTEXT` clears only the window and homes the cursor to the window's top-left. `BAS_SCROLL` scrolls only the window (`BAS_WSCRL`). `BAS_NEWLINE` goes to the window's left edge.
  - `BAS_PCHR`:
    - wraps at the window's right edge;
    - cursor codes `$1C`-`$1F` stay in the window;
    - `$0B` homes to the window's top-left and `$0C` clears the window;
    - new `$0E` shifts rows from the window's top row through the cursor row up by one and blanks the cursor row;
    - new `$0F` shifts rows from the cursor row through the window's bottom row down by one and blanks the cursor row;
    - the cursor does not move ("HuBASIC の実測").
  - `BAS_PZONE` (the `PRINT ,` separator) pads to the next 10-column stop of the absolute screen column. When that stop is past the window's right edge, it writes spaces to the edge, wraps, and if the wrapped position is not a stop, pads on to the next stop. Before this change it called `BAS_NEWLINE` without writing the spaces.
  - `BAS_PRTAB` (`TAB(n)`) compares with the absolute column `BAS_CX`; it is unchanged.
  - `BAS_INPUT`: BS stops at the window's left/top edge.
- `docs/HUBASIC.md` at 10cf481:

    - CONSOLE:

    - HuBASIC's `INPUT` re-reads the line from the screen and pushes lines up when the input wraps; hubasic2sl takes only the typed characters and does not push lines up.
    - `CSIZE 1`/`3` `PRINT#0` may wrap differently at the bottom edge or inside a window.
