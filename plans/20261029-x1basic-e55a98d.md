# X1Pen: import X1 BASIC Editor e55a98d (PCG hex digits separated by spaces)

## Purpose

The X1 BASIC Editor (HuBASIC tab of X1Pen, an iframe) is copied from `ho-ogino/x1-basic-editor` at one commit into `assets/x1basic/`. Its PR #8 is merged at `e55a98d5683fe950d83073202c489d5354859560`. The current copy is `31f309b0c36d3ae82758c053e4c3c5aa25a9a719` (PR #139). Re-import it so that, in X1Pen, "選択からPCG設定" also takes 48 hex digits on one line that are separated by spaces or tabs, such as `970 DATA 0000000000010003 0007030707020301 000000000702031D`. The owner asked for this now, without a version bump.

Non-goals:
- No change to the editor itself, which is owned by the x1editor Province.
- No change to X1Pen's host adapter API, Share, automation or MCP.
- No change to the HuBASIC converter bundle. The slang `MIRROR$`/`HEXCHR$`/`MUSIC` update and its reference review are a separate, later PR.
- No version bump and no production deploy; both are the owner's.
