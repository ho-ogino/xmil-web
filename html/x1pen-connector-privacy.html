X1Pen Connector Privacy Policy

Privacy policy for the X1Pen Connector browser extension

Effective: August 4, 2026

Purpose

X1Pen Connector connects an X1Pen browser tab selected by the user to an x1pen-mcp server running on the same computer. This lets the user's configured MCP client assist with X1Pen program development.

X1Pen Connectorは、ユーザーが選択したX1Penタブを同じコンピューター上のx1pen-mcpサーバーへ接続し、設定済みのMCPクライアントによるプログラム開発支援を可能にします。

Data handled

After the user accepts the disclosure and chooses Connect this tab, the extension may handle only the data needed for this purpose:

  • The selected X1Pen tab's title, URL, connection status, and program revision.
  • X1Pen FuzzyBASIC, SLANG, and assembly source requested by the MCP client.
  • Validation results, execution status, and emulator screen captures requested by the MCP client.
  • The local bridge port and six-digit pairing code entered by the user.

接続への同意後、選択したX1Penタブのタイトル・URL・接続状態・リビジョン、MCPクライアントが要求したプログラムソース・検証結果・実行状態・画面キャプチャ、およびユーザーが入力したローカル接続情報を取り扱います。

Use and transfer

The extension uses this data only to provide its single purpose. It sends data to the paired x1pen-mcp process over a loopback WebSocket connection to 127.0.0.1. It does not send data to a server operated by the developer and contains no analytics, advertising, or tracking.

The local MCP server returns requested data to the MCP client selected and configured by the user. That client may transmit program source, screen captures, or related results to its configured AI provider. Such processing is governed by the terms and privacy policy of the user's MCP client and AI provider.

データは単一目的の提供にのみ使用し、127.0.0.1のループバック接続を通じてペアリング済みのx1pen-mcpへ送信します。開発者のサーバーへの送信、アクセス解析、広告、追跡は行いません。MCPクライアントからAIプロバイダーへの送信には、各サービスの利用規約とプライバシーポリシーが適用されます。

Storage and deletion

The bridge port and pairing code are stored in Chrome local extension storage so the local connection can be restored. Connected-tab metadata is stored in Chrome session storage. Program source and screen captures are not retained by the extension.

Users can disconnect a tab from the popup. Removing the extension or clearing its extension data deletes its saved local configuration.

ポートとペアリングコードはChromeの拡張機能用ローカルストレージへ、接続タブ情報はセッションストレージへ保存します。プログラムソースと画面キャプチャを拡張機能内へ保持しません。切断、拡張機能の削除、または拡張データの消去により保存情報を削除できます。

Limited Use

The use and transfer of information received from Google APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is not sold, used for advertising or profiling, or made available for unrelated human review.

Google APIから受け取った情報の使用と転送は、Limited Use要件を含むChrome Web Store User Data Policyに準拠します。データの販売、広告・プロファイリングへの使用、目的外の人手による閲覧は行いません。

Contact

Questions and deletion requests can be submitted through the X millennium Web issue tracker.
