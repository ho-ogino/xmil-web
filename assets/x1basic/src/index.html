X1 BASIC Editor
X1 のアスキーセーブを、そのままの字形で編集します。
  • 記号は右のパレットから挿入できます。カナはIMEで入力できます。
  • 青い文字は制御コードです。編集画面で画面移動は実行しません。
  • 「コード・記号名で挿入」では \xHH や \{heart} が使えます。
  • アプリ内のコピー＆ペーストは元のバイトを保持します。外部向けには記号をエスケープ表記でコピーします。
  • 表現できない文字の入力・貼り付けは、変更を反映せず通知します。
  • 既存の改行は保持します。「新しい改行」は、これから入力する改行だけに適用します。
  • 上書き前のファイルを .bak に一度だけ保存します。既存の .bak は上書きしません。
  • PCG定義を選択して「選択からPCG設定」で確認できます。「文字列のみ」は初期値ONです。定義はファイルを切り替えても保持し、終了で解除します。PCG一覧の画像クリックで文字を挿入できます。
  • Ctrl（Macは⌘）+ O / S / F / Z、Shift + Z、I に対応しています。
内蔵字形：X1互換フォント / 美咲フォント
対応サイズ：2 MiBまで
